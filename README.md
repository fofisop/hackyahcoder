A project for the ysws "hackyeah!" 
What is this project: 
It is a short game which involves memorizing lines to be able to read the next page of the small comic! Based on theatre. I miss doing css! :D This was fun.
How to use this project:
Read the instructions on the page. (Memorize the line presented in BOLD).
Continue on to read a page of the comic.
Continue on to write down the line from the page earlier and if its right, the loop goes around again. (If that makes sense).
